# Common work words

In short: everyday work words that English IT text uses. One Vietnamese form each. Modes and rules: [README.md](README.md).

| English | Vietnamese |
|---|---|
| team (as a noun) | nhóm (nhóm vận hành, nhóm sản phẩm) |
| owner | người phụ trách |
| tool | công cụ |
| workflow, process | quy trình |
| platform | nền tảng |
| automation | tự động hóa |
| deploy | triển khai |
| review, approve | duyệt |
| dashboard, pipeline, prompt, agent | keep |
| model (AI) | mô hình AI (never "mô hình" alone: readers take it as a business model or a mock-up) |
| budget | ngân sách |
| scale (company) | mở rộng quy mô |
| leaver | người nghỉ việc |
| user (staff who use internal systems) | nhân viên, when the same text also has users of a product ("người dùng") |
| user (of an app) | người dùng |
| role | vai trò; first use: vai trò (tập hợp quyền giao cho một người) |
| permission, access | quyền truy cập |
| resource (things under a project) | name the kinds, for example "dữ liệu, ứng dụng và tài khoản". For readers outside IT, never "tài nguyên" alone: test readers took it as natural resources |
| internal app, internal software (holds resources) | phần mềm nội bộ (when "ứng dụng" in the same text means apps for customers) |
| metadata | dữ liệu mô tả (metadata) |
| one instance (of a system) | một bản cài đặt ("một bản" alone reads as a copy or a version; version = phiên bản) |
| plug in, connect (teams to a shared system) | cùng sử dụng ("kết nối với hệ thống" is vague) |
| use (verb, formal text) | sử dụng; "dùng" only in "người dùng"; shared = "sử dụng chung", never "dùng chung" ("dùng" reads as spoken) |
| dev team | nhóm phát triển phần mềm ("nhóm phát triển" alone is unclear: business development or product?) |
| pass/fail | đạt hoặc không đạt |
| seat (licence) | suất sử dụng phần mềm (seat); "seat owner" = người giữ suất sử dụng |
| test (verb, general) | thử nghiệm, kiểm tra; software testing: kiểm thử (tech.md) |
| run (a system) | vận hành |
