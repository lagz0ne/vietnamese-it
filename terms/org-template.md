# Organization terms

In short: copy this file to `org.md` and fill it in. Names here stay as they are. Tools and systems that readers may not know get a role gloss at the first use (rule VI-2a).

Gloss at first use: ToolA, ToolB

## Names

| Name | Mode | Note |
|---|---|---|
| Công ty ABC | keep | Organization name. Use it only in titles, covers and when the text compares the organization with others (VI-1b) |
| ToolA | keep + gloss | ToolA (hệ thống quản lý tài khoản và đăng nhập) |
| ToolB | keep + gloss | ToolB (công cụ theo dõi quảng cáo của thị trường) |

## Name vs generic word

When an initiative has an English name, keep the name only when the text means the initiative. For the generic idea, use the Vietnamese word. Example: "Platform" (initiative name) and "nền tảng" (generic idea).
