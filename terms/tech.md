# Tech terms

In short: the default pack for software products, interfaces, data, cloud, security and development. Modes and rules: [README.md](README.md).

Source marks: **M** = Microsoft Terminology Collection, Vietnamese (most used form; looked up with `tools/tbx_lookup.py`). **G** = Google Vietnamese interface or docs. No mark = common Vietnamese usage. When Microsoft lists more than one form, the note says so. When the Vietnamese forms are not stable (several forms, none common), the term stays English (keep), as the CNCF Vietnamese glossary does.
